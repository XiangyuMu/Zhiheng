# 结论适用性（Issue #5）

结论的审核身份与当前适用性分开保存。详情返回 `applicability`，包括状态、原因、受影响版本、证据和事件历史。`suspended` 表示当前不能作为依据；`review_required` 表示需要复核，尚未自动暂停。后台 worker 扫描有效期，读取上下文时也检查到期；正式检索视图在 worker 尚未运行时仍排除已过期结论。

创建或编辑草稿时可设置带时区的 `valid_until`。已确认前提也可包含 `valid_until`。自动关联个人事实的前提格式如下：

```json
{
  "text": "住在北京",
  "confirmed": true,
  "state_key": "profile.city",
  "value": {"text": "北京"}
}
```

只有确认前提的 `state_key` 与更新匹配、且结构化值发生变化时才自动暂停。纯文本前提不进行语义猜测；未确认前提仍作为假设使用。个人信息更新服务中的明确更新及用户确认的冲突会通知结论；推测、引用、假设或未解决的个人信息冲突只产生复核提醒。

暂停不修改结论、旧前提或来源，也不自动恢复或修订。修订仍走草稿和用户审核流程。缓存引用及已加载的回答上下文复用现有授权校验，重新检查正式知识视图，因此暂停后不能继续授权旧证据。
