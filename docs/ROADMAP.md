# 知衡产品与开发路线图

路线图以“可验证能力”而非代码模块作为进度单位。具体工作由 GitHub Issue 跟踪，本文只维护阶段目标、进入条件和完成标准。

## Milestone 0：产品与架构基线

目标：将 PRD 转化为可实施的系统设计和测试策略。

- [x] 完成产品定位和完整 PRD
- [ ] 完成领域分类词典与记忆字段字典
- [ ] 完成系统架构与组件边界
- [ ] 完成 SQLite 数据模型
- [ ] 完成文件、数据库与派生索引的权威来源约定
- [ ] 完成 RAG 评测集和记忆评测集设计
- [x] 确认持续进化的八项核心决策
- [ ] 完成学习信号 Schema 与提案数据模型
- [ ] 完成提案状态机、审核权限和发布门槛
- [ ] 确定第一版技术栈和部署方式

完成标准：关键架构决策已记录；MVP 可以拆成独立、可验收的 Issue。

## Milestone 1：证据库与知识导入

目标：可靠保存原始资料，并生成可重建的结构化与检索数据。

- [ ] 单用户认证和基础服务器部署
- [ ] PDF、网页、Markdown、图片导入
- [ ] 原始文件、来源和版本保存
- [ ] 文本提取、分块和元数据处理
- [ ] MECE 主分类、标签和关系建议
- [ ] SQLite 元数据与 FTS5 全文检索
- [ ] 本地向量索引与混合召回

完成标准：导入资料后能够通过标题、术语和语义问题找到原文证据，删除后派生数据同步失效。

## Milestone 2：用户记忆与记忆中心

目标：形成可解释、可确认、可撤销的个人画像。

- [ ] 身份、角色、目标、项目、兴趣、偏好和约束模型
- [ ] 工作记忆、轨迹和长期记忆分层
- [ ] 候选记忆生成
- [ ] 确认、修改、拒绝和批量处理
- [ ] 版本、证据引用、删除与回滚
- [ ] L0 核心画像与 L1/L2 按需加载

完成标准：未经确认的推断不会影响正式画像或推荐；所有正式记忆均可追溯和回滚。

## Milestone 3：知识问答与决策支持

目标：在个人上下文和可靠证据基础上回答问题并辅助决策。

- [ ] 结构化直查、普通混合 RAG 和 Agentic RAG 路由
- [ ] 带原文引用的知识问答
- [ ] 冲突、时效和证据不足提示
- [ ] 决策问题、约束、方案、风险和假设模板
- [ ] 决策记录与复盘

完成标准：回答能区分知识证据、用户画像、模型推理和假设；决策建议不执行外部动作。

## Milestone 4：知识缺口与可验证进化

目标：主动指出值得了解的知识，并验证系统是否真的变好。

- [ ] 目标依赖与知识库覆盖分析
- [ ] 知识缺口推荐和解释
- [ ] 在线轨迹与反馈记录
- [ ] 结果、过程、质量三层轨迹评价
- [ ] 离线跨轨迹候选提炼和更新对象路由
- [ ] 固定基准＋动态边界/迁移/保留/安全集
- [ ] Proposer/Reviewer 独立审核
- [ ] 检索与回答策略 canary、晋升和回滚
- [ ] 周期＋事件触发的睡眠学习和淘汰

完成标准：推荐均有明确目标或知识结构依据；至少一个检索与回答策略提案完成“评价、跨轨迹归纳、独立审核、多集验证、canary、稳定或回滚”的完整闭环。

## 暂不排期

- 多用户和共享知识空间
- 自动交易、发信、下单等外部行动
- 个人模型训练或持续微调
- 复杂图数据库
- 无确认的外部知识自动入库
