## 能力与边界

| 能力 | 首版可验证范围 |
| --- | --- |
| 资料导入 | 浏览器粘贴文本、持久化任务、独立 Worker、可检索状态、搜索及原文定位 |
| 对话结论 | 保存原始材料，将独立判断提炼为草稿，保留前提及来源；人工批准后取得正式资格 |
| 分类 | 确定性建议，人工审核；唯一主领域与跨域关联，合并／拆分逐条迁移 |
| 使用资格 | 待审核、拒绝、暂停及未完成导入不进入正式回答；假设保留条件 |
| 个人记忆 | 明确且无冲突的个人陈述可自动记忆；冲突由用户确认；缺失信息可补充、延期或跳过 |
| 恢复 | 真实 restic 备份与隔离恢复、数据库升级、原文校验，以及最新擦除账本重放 |

自动提炼采用可解释规则；受控模型响应只证明处理契约。固定 50 段合成集的门槛为
结论召回 ≥90%、前提保留 ≥95%、原文偏移有效率 100%、负例误提炼为 0。
它不能证明开放域质量。未识别表达提供原文与手动补充入口；用户同意记录也不等于结论无条件真实。

LLM 分类、更强语义关系、多用户隔离、公网 HTTPS、生产服务器/容器演练、开放域提炼质量、
完整向量路径及外部 Provider 可用性签收均为后续增强，不宣称首版已支持或已验收。
未配置可选 PDF 解析能力时显示 `unsupported`；失败、不支持和部分完成均不获得正式检索资格。
默认回答无需配置外部模型，使用提取式回答；模型增强不是安装前提。

另建目录重跑，不覆盖原证据。依赖弃用警告保留在日志中，不等于功能失败。
