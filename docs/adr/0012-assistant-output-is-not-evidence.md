# 助手输出不是依据

- **Status:** accepted
- **Date:** 2026-11-04

如果知识库把自己的回答当作依据保存，错误的或过于肯定的回答会在之后被检索、引用、再次加强，越用越偏。为避免这种自我强化，我们决定**助手输出**既不是个人陈述，也不是外部依据：它不能触发自动记忆；由它提炼的草稿须标明来源，并与其他结论草稿一样逐条审核；正式知识的依据须能追溯到原始材料、用户陈述或已批准的正式知识，仅以助手推理为依据时须如实显示。**综合结论草稿**以参与归纳的正式知识为依据，未批准的综合结论草稿也不作为下一轮反思的输入。我们接受少收录一部分由对话推理得出的结论，换取正式知识的来源始终可信。

## Considered Options

- **把助手回答视为普通对话内容，与用户陈述同等提炼**：收录最多，但助手的错误能变成正式知识的依据，未采纳。
- **只要用户批准即可以助手推理为唯一依据且不作标记**：审核仍在，但之后无法区分哪些知识只有助手推理支持，未采纳。
