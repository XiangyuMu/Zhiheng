# 主领域与记录类型分离

原分类将个人档案与经历和财务、健康等主题领域并列，混合了内容性质与主题两个维度，导致同一条个人复盘天然符合多个主领域。用户确认将个人档案与经历作为独立的记录类型维度；主领域继续表达知识的主要主题，跨领域关系表达其他相关主题。

这一选择放弃了把所有个人经历集中放进一个主领域的便利，使个人经历能够按主题参与检索，同时保留按记录类型查看的可能。用户确认主题体系须同时覆盖学科知识与个人生活实践，并同意以分类规范中的十四个主领域作为新版起点。该清单不是已经证明严格 MECE 的最终分类，后续按实际条目检验边界与覆盖范围；完整记录类型词汇仍待细化。

原始材料完整保留；其中可独立理解的结论分别提炼为知识条目，每条带自身的成立前提、主领域和原文来源。一段跨领域对话可以产生多个分别归类的条目，无需为整段对话的全部结论强行指定同一个领域。提炼条目仍须遵循[结论审核规则](0002-conclusion-approval-and-applicability.md)，保留原文不等同于批准其中所有判断。

新条目的主领域和跨领域关联由系统建议，随结论一起展示，用户可以修改后批准。已有条目的分类调整须经用户确认；领域新增、合并或拆分须展示理由及受影响条目，经用户同意后执行并保留历史归属。

现有 `personal_archive_experience` 数据需要逐项按主题确定归属，不能简单迁入同一个领域。历史标识仍须可追溯。分类规则见[Domain Taxonomy](../product/domain-taxonomy.md)。

2026-10-20 修订（#60）：领域目录只保留一套启用的主领域，即上述十四个 v2 主领域。v1 的英文领域停用但不删除，以便追溯历史归属。`relationships_communication` 保留原标识，原地更新为「人际关系与沟通」。新导入的资料不再选择主领域，先以 `unassigned` 进入未分类，由用户批准系统建议的主领域。目录外的旧领域标识（如 `personal.notes`）通过逐项确认的历史领域迁移归入主领域；迁移保留每条资料迁移前后的映射，可以回滚。
