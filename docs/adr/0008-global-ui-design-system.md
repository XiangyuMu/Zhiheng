# 全局知识库 UI 设计系统

- **Status:** accepted
- **Date:** 2026-10-07

知识库页面沿用现有 `knowledge-agent.css` 的信息架构和主色语义，抽取为所有页面共享的设计令牌和组件样式。令牌覆盖背景、表面、文字、弱文字、边框、主色、成功/警告/错误、间距、圆角、控件高度、阴影和响应式断点；按钮、表单、表格、弹窗、空态、加载态、错误态和状态提示使用同一套视觉与可访问性规则。

Review Center 和 Taxonomy Center 先迁移到共享系统，再核对登录、研究、知识库、记忆、演化和设置页面。迁移保持现有导航、信息架构、审核语义和业务流程；Provider 模型配置新增的业务行为由 ADR 0007 单独决定。窄屏使用 `<=900px` 作为主要折叠断点，表单变为单列，表格允许横向滚动，弹窗接近全宽。

组件必须有键盘导航、可见焦点、正确标签关联、足够对比度和可读的异步错误/加载状态。验收使用真实浏览器覆盖 Provider 编辑页、Review Center、Taxonomy Center、知识库及移动视图，并验证默认、加载、成功、错误、空和弹窗状态；截图和交互结果绑定同一提交 SHA。
