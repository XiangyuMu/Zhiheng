# 统一的待处理

- **Status:** accepted
- **Date:** 2026-10-20

[ADR 0002](0002-conclusion-approval-and-applicability.md) 接受审核积压的代价，审核因此成为产品瓶颈；而待处理事项原本分散在集中审核、个人上下文的候选页、资料库的未分类列表和分类中心的待审核调整四处，动作和延后语义各不相同。我们决定由**待处理**作为处理全部待处理事项的唯一位置，其他页面只显示该类型的数量并链接到筛选后的待处理，不再保留各自的处理按钮；侧栏在每个页面显示未延后的待处理事项数量。这改变了 [ADR 0008](0008-global-ui-design-system.md) 要求迁移时保持的导航与信息架构。

为维持 ADR 0002「同意针对具体内容」的要求，批量**批准**只适用于低风险类型：分类建议、分类调整条目和明确陈述形成的记忆候选。结论草稿、关系建议和推断画像候选必须逐条批准，且只有在详情中完整展示内容、前提、来源和与已有知识的关系时才能批准。批量拒绝和延后适用于所有类型。我们放弃了全类型批量批准带来的速度，换取正式知识仍由用户逐条认可。

**延后**对所有类型含义一致：事项离开默认视图、不计入数量、没有自动唤醒时间，只在用户恢复或系统再次需要时回到待处理；延后不构成对任何内容的确认。为此，记忆候选新增延后，分类调整新增拒绝。个人信息冲突和待补充的提炼不映射为批准或拒绝，须在详情中选择、澄清或补充。

## Considered Options

- **聚合视图、保留各页处理按钮**：保留五套语义不同的处理界面，不一致问题持续存在，未采纳。
- **全类型批量批准并修订 ADR 0002**：速度最快，但用户同意退化为对一批标题的认可，未采纳。
