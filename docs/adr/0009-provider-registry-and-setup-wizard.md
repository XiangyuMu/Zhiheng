# Provider Registry 与配置向导

- Status: accepted
- Date: 2026-10-08

借鉴 Cherry Studio 的预设目录和配置向导，将公共 Provider 预设定义与用户实例分离，避免把预设存在误认为协议已经实现或服务已经可用。预设提供名称、默认地址、认证、协议、发现方式和能力建议；用户实例拥有独立配置和密钥。能力仍须用户确认，密钥继续遵循 ADR 0006 的加密和不回显要求。

模型目录支持远程发现、无发现接口时的静态目录及手动登记。刷新失败保留历史目录；成功刷新后缺失的模型保留并标记过期，由用户处理，不删除默认模型配置。过期模型的路由资格继续受 ADR 0007 约束，保留配置不代表仍可调用。

配置向导允许分步保存与恢复，区分目录失败、连接失败、不支持和密钥不可用。启用前须地址及协议合法、凭据可用（明确免密除外）、至少一个已确认模型通过实际调用验证；验证绑定实例、模型及协议，不要求所有模型成功。不支持的协议可展示预设及保存草稿，但禁止启用和路由，禁止静默降级协议。

删除旧配置实现及旧 API/UI，提供一次性数据迁移，保留已有密钥、模型确认和默认路由，不无故改变地址或启用状态；无法映射的配置标记不支持并提示重新配置。旧实现退出与历史数据保留是两个独立决定。

官方 OpenAI、DeepSeek 使用固定官方地址；其他预设按已确认地址规则提供默认值或允许覆盖。自定义地址采用 HTTPS 或受控本地回环校验，禁止 URL 凭据、查询串及片段。首次删除动作采用归档/停用并使默认路由失效；永久删除须用户明确执行，才删除模型及密钥。删除密钥立即禁用实例。

首批目录包含 OpenAI、DeepSeek、Anthropic、Gemini、Ollama、LM Studio、OpenRouter，并加入硅基流动及 Embedding 场景。硅基流动使用 `https://api.siliconflow.cn/v1` 和 `GET /models?sub_type=embedding` 发现 classic text embedding 模型；当前不把其 VL Embedding 作为首版默认候选，也不假定所有模型支持可调维度。Embedding generation 必须绑定模型身份、版本、维度和用途，切换模型或维度时新建 generation 并重建，不能复用旧向量索引。首批目录收录不等于所有适配器均可调用。
