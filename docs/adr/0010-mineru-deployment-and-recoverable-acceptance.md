# MinerU 独立主解析器与可恢复的本地部署

- Status: accepted
- Date: 2026-10-09

本地单用户部署允许显式选择 MinerU 为主解析器，保留 DeepDoc 独立选项，不再以已配置 DeepDoc 作为使用 MinerU 的必要前提。使用网关对接知衡的解析协议和 MinerU 上游协议，以保留 manifest、来源身份与发布资格边界；任务和 manifest 必须如实记录实际解析引擎。

部署提供可重复使用的启动、停止、健康检查与诊断入口，以及持久模型缓存。网关持久记录尝试与上游任务关联；重启后先查询原任务，无法恢复则明确失败并允许手动重试。不承诺上游恰好执行一次，不因重启无条件重发；正式知识发布必须幂等，拒绝失效租约回写，保留原文并隔离不完整结果。这是在恢复能力与不确定网络提交之间的明确取舍。

真实 Comments.pdf 的解析、manifest、索引、检索和原文定位，与 DeepSeek 基于该 PDF 的正确引用回答分别验收，且两者都须通过；Worker/网关解析期间重启也是必过场景。不绕过发布或授权规则，不增加 Rerank。

预热与解析分开计时：预热超过 30 分钟保存诊断并结束该轮；预热后本文件单次解析及索引预算为 5 分钟，外部瞬时错误最多自动重试 2 次，仍失败则保留终态与手动重试入口。这是本次环境与文件的初始验收阈值，不是所有 PDF 的产品 SLA。沿用 ADR 0004/0005 的同 SHA 证据要求与正式检索资格。

详细执行及证据清单见 [部署与真实文件验收记录](../product/discovery/mineru-real-file-acceptance.md)。本决策已接受，不代表实现或验收已经完成。
