## Problem Statement

用户已经配置 DeepSeek 和 Embedding 服务，但尚不能证明真实 PDF 可以从页面导入，经独立 Worker 解析、建立索引、被检索并用于有引用的回答。现有 Comments.pdf 上传进入 unsupported；上游 MinerU 的健康检查不代表知衡解析协议可用。已有网关、测试和独立模型探测属于实现或局部证据，不能替代整条链路验收。

本规格综合用户已接受的 Q1–Q6 与 ADR 0010，并沿用 ADR 0004/0005 的同提交证据与正式检索资格要求。

## Solution

提供可重复使用的本地 MinerU 部署，持久保存模型缓存，支持明确选择 MinerU 为主解析器。用户从真实页面上传 Comments.pdf 后，能够看到任务进度及可靠终态，搜索命中本次导入资料，打开对应页原文，并获得 DeepSeek 基于该资料生成的正确引用回答。

解析过程中重启 Worker 或网关后，系统应查询原任务继续处理；无法恢复时明确失败并允许手动重试。以真实运行保存证据，分别判定解析/索引/检索及原文定位、DeepSeek 引用回答、中断恢复三组结果，三组均通过才算本规格完成。

## User Stories

1. As a 本地用户, I want 通过固定入口启动解析服务, so that 不需要每次手工拼装进程和参数。
2. As a 本地用户, I want 停止和检查本次部署的服务, so that 能管理资源并定位不可用组件。
3. As a 本地用户, I want 模型缓存持久保存, so that 服务重启不必重新下载已有模型。
4. As a 本地用户, I want 区分网关存活、上游存活和模型就绪, so that 不会把健康检查误当成解析可用。
5. As a 本地用户, I want 独立选择 MinerU 为主解析器, so that 不必先配置 DeepDoc。
6. As a 本地用户, I want 保留 DeepDoc 的独立配置选项, so that 现有解析选择不被伪装或无故移除。
7. As a 本地用户, I want 从真实页面上传 Comments.pdf, so that 验收覆盖实际使用入口。
8. As a 本地用户, I want 独立 Worker 消费持久导入任务, so that 关闭页面不会代替或取消后台处理。
9. As a 本地用户, I want 每次解析保留来源身份和实际引擎, so that 结果可追溯到正确的文件与尝试。
10. As a 本地用户, I want manifest 与原文摘要可校验, so that 来源错误或损坏不能被正式发布。
11. As a 本地用户, I want 不完整的页面或资源被明确标识, so that 内容不会静默丢失后仍显示成功。
12. As a 本地用户, I want 原文、索引和任务资格一致后才显示可检索, so that 未完成材料不会进入回答。
13. As a 本地用户, I want 搜索命中本次上传对象, so that 历史同名资料不能冒充本次导入成功。
14. As a 本地用户, I want 点击引用回到 PDF 对应页和原文, so that 能核对结论依据。
15. As a 本地用户, I want DeepSeek 根据该 PDF 生成正确回答, so that 系统不仅返回证据列表。
16. As a 本地用户, I want 回答引用实际支持其内容, so that 模型连接成功不会被误当成回答正确。
17. As a 本地用户, I want 材料未提供答案时明确说明证据不足, so that 系统不会编造答案。
18. As a 本地用户, I want 网关或 Worker 重启后查询原上游任务, so that 不会无条件重复提交解析。
19. As a 本地用户, I want 无法恢复的任务明确失败并提供重试入口, so that 不会永久停留在处理中。
20. As a 本地用户, I want 旧 Worker 或重复回调不能重复发布正式版本, so that 恢复过程保持数据一致。
21. As a 本地用户, I want 预热和任务执行有明确预算与诊断, so that 能区分下载等待、解析耗时和真实失败。
22. As a 本地用户, I want 外部瞬时错误只有限重试, so that 不会无限调用服务或无限轮询。
23. As a 验收者, I want 成功与失败都保存完整运行证据, so that 中途异常不会抹掉失败原因。
24. As a 验收者, I want 最终证据绑定同一提交的干净检出, so that 历史绿色测试不被当作当前版本通过。
25. As a 本地用户, I want 私人文件、凭据和原始回答仅保存在受限本地证据中, so that 发布规格或提交代码不泄露个人材料。

## Implementation Decisions

- 本地单用户部署；允许显式选择 MinerU 主解析器，保留 DeepDoc 独立选项，不以 DeepDoc 配置作为 MinerU 启用前提。任务、尝试和 manifest 记录真实引擎。
- 保留知衡现有解析协议边界，由网关转换为 MinerU 上游任务协议。生产客户端、任务执行器、fallback 和网关完整传递来源身份、任务身份、尝试身份、lease 与摘要。
- 补齐部署配置及启动、停止、检查、诊断入口，持久保存模型缓存。记录实际镜像版本、模型和资源状态；退出码 137 不单独作为 OOM 证明。
- 网关只能读取受控对象存储内的来源并校验摘要，输出 manifest 和被引用资源必须可读取、可校验。不能静默丢弃资源后宣称完整成功。
- 持久记录本地尝试与上游任务关联；重启先查询原任务。任务不可恢复或提交结果不确定时明确诊断，不无条件重发。允许明确失败后的手动重试，不承诺上游恰好执行一次。
- 正式发布幂等，并拒绝失效 lease 回写；失败与重试不得丢失原文、混淆尝试或重复生成正式版本。
- 沿用正式检索资格：任务 succeeded、原文存在、索引指针存在三者同时满足。解析成功本身不等于完成索引；queued、processing、failed、unsupported、partial 不进入正式回答上下文。
- 使用已配置且合格的 Embedding 与 DeepSeek。确认实际调用和返回结果；禁止静默替换模型、使用模拟结果或绕过发布/授权门禁。
- 预热下载独立计时，超过 30 分钟保存诊断并结束本轮；预热后 Comments.pdf 单次解析及索引预算为 5 分钟，外部瞬时错误最多自动重试 2 次（初次尝试之外）。失败保留稳定终态、原因和手动重试入口。
- 报告分列各次尝试耗时、重试次数与总耗时，超时不算通过。上述预算只适用于本次文件与环境，不是所有 PDF 的产品 SLA。
- 复用当前浏览器、任务状态和引用接口；补强当前请求等待、当前任务身份断言及失败报告，避免旧页面结果或同名资料造成假通过。
- 保护原有无关未提交工作；个人原文、账号密码、Provider 密钥和未经脱敏的调用内容不进入 Git 或公开票据。

## Testing Decisions

已确认的主要测试边界为真实浏览器 → 真实 API → 独立 Worker → 实际 MinerU/模型服务 → 检索与引用页面；重启恢复也是必过行为。复用已有解析客户端协议、manifest 校验及真实数据库 lease 测试作补充，不为每个内部函数建立新测试接口。

好测试验证用户可观察行为、来源关联与发布资格，不仅检查响应码、数据库记录存在或模拟调用次数。契约测试可使用受控响应定位边界问题，但不得作为真实外部服务验收替代品。

### 必过验收

- [ ] 干净检出可迁移数据库并启动 API、独立 Worker、网关与实际 MinerU；重复启停及持久模型缓存行为可验证，日志区分存活与模型就绪。
- [ ] 生产客户端提交可被网关接受；主路径及 fallback 保留正确 evidence 身份和实际 backend；非法来源、摘要不匹配及不完整资源不能被成功发布。
- [ ] 登录页面后上传 Comments.pdf；记录输入摘要及本次 task/attempt/evidence 身份，实际 MinerU 完成解析并生成摘要正确、来源匹配的 manifest。
- [ ] 实际 Worker 发布并使用已配置 Embedding 建立索引；该对象满足正式检索资格，页面能找到本次资料，搜索命中并打开正确 PDF 页/原文。
- [ ] 预先从原文件建立可核对的问题和预期依据；DeepSeek 实际生成回答，内容与原文一致，引用属于本次对象且支持回答。证据列表或固定降级文字不算成功回答。
- [ ] 用原文件不包含答案的问题验证证据不足行为；不得把其他历史资料或旧页面回答误判为本次结果。
- [ ] 分别覆盖解析中 Worker 重启和网关重启；原上游任务存在时查询恢复，不无条件重发。不存在或状态不确定时明确失败并可重试。
- [ ] 旧 lease、重复完成和重试不会产生重复正式版本；原文保留，不完整结果隔离。
- [ ] 验证上游不可用、外部模型错误、partial、unsupported、预算超时的真实可观察状态；故障注入须标明，正常成功链路不得模拟。
- [ ] 每次浏览器检查等待本次请求和页面更新，轮询绑定当前任务；失败/超时以非零退出，finally 保存完整报告，不能根据整页出现某个终态词判通过。
- [ ] 保存同一最终 SHA 的迁移、启动、Ruff、全量 Mypy、完整 pytest 自然结束和真实浏览器证据；pytest 900 秒预算与功能通过分别判定，不复用旧提交结果。
- [ ] 持久证据包括命令、SHA、依赖/镜像/模型/浏览器版本、输入摘要、任务及尝试身份、manifest 摘要、索引身份、调用审计、引用核对、截图、日志、退出码及分阶段耗时。公开索引脱敏，完整个人证据留在本地受限目录。

既有测试先例包括 PDF manifest schema 测试、解析 Worker 客户端测试、数据库 lease fencing 集成测试、任务重试测试及真实浏览器导入/引用脚本。保留并修复这些边界，不重复创建等价测试设施。

## Out of Scope

- Rerank、检索算法全面改造、任意 PDF 的通用质量或性能保证。
- 生产多用户隔离、公网服务、生产服务器和 HTTPS 部署。
- 将 pypdf 提取、模拟 parser 或受控模型响应冒充真实 MinerU/DeepSeek 成功。
- 删除 DeepDoc 选项、静默变更已配置模型或绕过 G006 发布及授权规则。
- 修改无关 UI 工作、发布用户原文/凭据，或按历史 Issue 状态自动判定完成。
